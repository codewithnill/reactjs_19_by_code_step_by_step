# React JS 19 Full Course in Hindi

**Complete React learning repository from Code Step By Step**

From Vite setup and JSX fundamentals to React 19 hooks, routing, APIs, validation, and a practical mini project.

> **Learning note:** This repository records practical learning from the Hindi course **“React JS 19 Full Course in Hindi”** by **Code Step By Step**. The examples below are based on the source files developed throughout the course.

## 📚 What this repository contains

This repository follows a complete React learning path. It begins with creating a React application using Vite and understanding the generated project structure. It then covers JSX, components, events, state, props, forms, list rendering, hooks, styling, React Router, Tailwind CSS, API integration, JSON Server, CRUD operations, validation, and selected React 19 features.

The `react-blog` project is a tutorial workspace rather than one single production application. Several example components remain in the repository so that each lesson can be studied independently. The final project history also includes a color-mixer mini project.

## 🎯 Learning outcomes

By studying the roadmap and source code, you will be able to:

- Create a React application with Vite and understand its file structure.
- Build function components and reuse them inside other components.
- Write JSX with expressions, properties, fragments, and event handlers.
- Manage changing UI data with `useState`.
- Pass values, objects, arrays, children, and functions through props.
- Handle text fields, controlled forms, checkboxes, radio buttons, and dropdowns.
- Render arrays and nested arrays with `map()`.
- Use `useEffect`, `useRef`, `useFormStatus`, `useTransition`, `useActionState`, `useId`, `useReducer`, and `use`.
- Apply inline styles, external stylesheets, CSS Modules, styled-components, Bootstrap, and Tailwind CSS.
- Create routes, nested routes, layouts, dynamic routes, optional segments, redirects, and active navigation links.
- Fetch data from APIs and build local JSON Server CRUD workflows.
- Validate React forms and organize larger examples into reusable components.

function App() {

    inputRef.current.focus();
    inputRef.current.style.color='red';

    const [value,setValue]=useState(defaultValue);
    function toggleValue(val) {
        if(typeof val!='boolean') {
            setValue(!value);
